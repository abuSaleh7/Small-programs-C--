# Small C++ Programs Collection

A practical collection of small C++ programs for beginners and learners who want to practice core programming concepts through short examples.

## وصف المستودع (Arabic)
هذا المستودع يحتوي على مجموعة برامج C++ صغيرة للتدريب والتعلم. الأمثلة تغطي أساسيات مهمة مثل:
- الإدخال والإخراج
- الشروط والحلقات
- المصفوفات
- المؤشرات
- الدوال والكلاسات
- هياكل البيانات الأساسية مثل `stack`

## Why this repository?
- Beginner-friendly examples
- Quick programs for daily practice
- Useful reference for students learning C++ fundamentals

## Repository Structure
- `/C++/program_/` → separate small `.cpp` programs
- `/40_Project.c++` → large collection of commented C++ practice snippets

## How to Run
Compile and run any file with a C++ compiler:

```bash
g++ path/to/file.cpp -o app
./app
```

Example:

```bash
g++ "C++/program_/newfile20.cpp" -o app
./app
```
